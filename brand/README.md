# Fokus marka varlıkları

## Logo: Odak halkası

Üç çeyreklik bir kronometre yayı ve ortasında odak noktası. Tek fikir: **süre akarken dikkat merkezde kalır.** Uygulamadaki ilerleme halkasıyla aynı dili konuşur; 16 px'te de okunur.

| Dosya | Kullanım |
| --- | --- |
| `logo/final/fokus-symbol.svg` | Ana sembol (siyah, 256 birim tuval) |
| `logo/final/fokus-symbol-white.svg`, `-black.svg`, `-mono-ffb547.svg` | Tek renk sürümler |
| `logo/final/icon-any.svg`, `icon-dark.svg`, `icon-tinted.svg` | iOS uygulama ikonu (açık / koyu / renklendirilmiş); PNG'leri `logo/final/png/` ve `ios/Fokus/Resources/Assets.xcassets/AppIcon.appiconset/` |
| `logo/final/favicon.*`, `icon-*.png`, `site.webmanifest` | Web simgeleri |
| `logo/concepts/` | Değerlendirilen diğer konseptler (Akan F, Optik form) — taslak |

**Renkler:** kehribar `#FFB547` (yay), kırık beyaz `#EDEAE2` (nokta), gece zemini `#0E0F0C`. Tek renkte yay ve nokta aynı renktir.

**Kurallar:** Sembolün çevresinde en az nokta çapı kadar boşluk bırak; 16 px altında kullanma; döndürme, gölge, degrade ekleme; yayın açıklığı her zaman sol üstte kalır.

Sembol stroke tabanlıdır (yuvarlak uçlu yay); baskı/kesim için çizgiyi dolguya genişletin. Ticari marka taraması yapılmadı; yayından önce önerilir.
