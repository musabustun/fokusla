# Yaş derecelendirmesi — anket cevapları önerisi

Beklenen sonuç: **4+** (her soruya "Yok / Hayır"). App Store Connect → Uygulama Bilgileri → Yaş Derecelendirmesi.

| Soru | Cevap | Gerekçe |
| --- | --- | --- |
| Şiddet (çizgi film/gerçekçi), korku, cinsel içerik/çıplaklık, küfür, uyuşturucu/alkol/tütün, kumar, bahis, kutu açma (loot box) | Yok | Böyle içerik yok |
| Tıbbi/tedavi bilgisi, yetişkinlere yönelik/müstehcen tema | Yok | Yok |
| Rekabetçi oyun / simüle kumar | Yok | Oyun değil |
| Sınırsız web erişimi | Hayır | Uygulama bir tarayıcı değil; yalnızca GitHub ve Spotify bağlantıları sistem tarayıcısında/Spotify'da açılır |
| Kullanıcı tarafından oluşturulan içerik | Evet (1.0.2, Sosyal) | Yalnız kullanıcı adı ve oda adı; süzgeç, engelle, bildir var |
| Sohbet / mesajlaşma | Hayır | Sosyal'de mesajlaşma yok; iMessage paylaşımı Apple'ın uygulamasında |
| Yapay zekâ ile üretilen içerik | Hayır | Yok |
| Uygulama içi satın alma / abonelik | Hayır | Ücretsiz, premium yok |
| Reklam | Hayır | Reklam SDK'sı yok |
| Konum paylaşımı | Hayır | Konum kullanılmaz |

Yeni "Apple yaş derecelendirme" alanları (Apple, 2025'te 13+/16+/18+ eklemesiyle anketi güncelledi): tümü "Yok". Soru adları sürüme göre değişebilir; mantık aynı: hiçbir hassas içerik/özellik yok.

Hedef kitle: ortaöğretim/üniversite hazırlık öğrencileri. "Çocuklara yönelik (Kids)" kategorisi SEÇİLMEZ.
