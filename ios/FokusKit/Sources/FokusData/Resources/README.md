# FokusData kaynakları

- `yks-curriculum.json` — YKS müfredat kataloğu. Web `web/src/curriculum/` verisinden üretilir
  (bkz. `ios/README.md` → "Müfredatı güncelleme"). Elle düzenleme; kaynak web kataloğudur.
- `book-library.json` — gömülü kitap kütüphanesi. Web `web/src/library/` verisinden
  `npm run export:ios-library` ile üretilir. Elle düzenleme.
